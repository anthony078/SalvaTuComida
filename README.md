## 🎯 Sobre el proyecto

**HogarSmart** es una aplicación Android desarrollada en **Java** que ayuda a las familias a gestionar el inventario de alimentos de su hogar, reducir el desperdicio de comida y ahorrar dinero aprovechando mejor lo que ya tienen.

La idea nace de un problema cotidiano: **compramos comida que se vence antes de consumirla**. Esta app soluciona eso con recordatorios inteligentes, sugerencias de recetas y una lista de compras optimizada.

### ✨ ¿Qué puedes hacer con HogarSmart?

- 🥛 **Llevar un control** del inventario de alimentos disponibles
- ⏰ **Recibir avisos** de productos próximos a vencer
- 🍳 **Descubrir recetas** con los ingredientes que ya tienes
- 🛒 **Crear listas de compras** inteligentes y personalizadas
- 📊 **Visualizar estadísticas** de consumo semanal

## 🧩 Funcionalidades

| Módulo | Descripción |
|:------:|-------------|
| 🏠 **Inicio** | Panel principal con resumen del día, productos por vencer y estadísticas de consumo |
| 📦 **Inventario** | Lista completa de productos con filtros por estado (Urgente / Pronto / Bien) |
| 🍳 **Recetas** | Sugerencias de recetas basadas en los ingredientes disponibles |
| 🛒 **Compras** | Lista de compras pendientes y gestionable |
| 👤 **Perfil** | Información del usuario y configuración de la cuenta |
